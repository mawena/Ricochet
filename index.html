Ricochet
Installer Dernière version Code source

Vos machines à portée de téléphone, même sans IP publique

Chaque machine fait tourner un agent qui ouvre lui-même une connexion chiffrée vers votre relais. La connexion « ricoche » sur le relais : pas de port à ouvrir, ça marche derrière une box ou un NAT. Vous commandez tout depuis un navigateur.

L'agent, sur chaque machine (Ubuntu 24.04, amd64) :

curl -fsSL https://mawena.github.io/Ricochet/installer.sh | sudo sh

Le relais, sur le serveur public :

curl -fsSL https://mawena.github.io/Ricochet/installer.sh | sudo sh -s serveur

Le script ajoute le dépôt APT signé puis installe le paquet ; les commandes qu'il lance sont détaillées plus bas, pour qui préfère les taper soi-même.

Ce que fait Ricochet

Sans IP publique

L'agent se connecte en sortie (WebSocket sur TLS) et se reconnecte seul après une coupure : le PC derrière une box est joignable comme un serveur.

L'état d'un coup d'œil

Processeur, charge, mémoire, disques et durée d'allumage de chaque machine, en ligne ou non.

Un terminal dans le navigateur

Un vrai shell (xterm.js), redimensionnable, avec une barre de touches pour le téléphone : Échap, Tab, Ctrl, flèches.

Les fichiers

Parcourir les dossiers, télécharger et envoyer des fichiers de toute taille, par morceaux : un envoi coupé reprend où il s'était arrêté.

Protégé

Mot de passe Argon2id et code TOTP, jetons de machine révocables, en-têtes contre les requêtes forgées, politique de sécurité stricte.

Tout est noté

Connexions, machines ajoutées ou révoquées, terminaux ouverts et fermés, fichiers échangés : un journal d'audit consultable dans l'interface.

Léger

Relais et agent en Rust, un binaire chacun, un service systemd chacun ; le relais garde ses données dans SQLite.

Installer

Pour Ubuntu 24.04 et les distributions Debian équivalentes, sur processeur amd64. Une fois le dépôt ajouté, sudo apt upgrade apporte les nouvelles versions.

  1. Ajouter la clé qui signe le dépôt :

    sudo curl -fsSLo /usr/share/keyrings/ricochet.gpg https://mawena.github.io/Ricochet/apt/ricochet.gpg

  2. Ajouter le dépôt :

    sudo curl -fsSLo /etc/apt/sources.list.d/ricochet.sources https://mawena.github.io/Ricochet/apt/ricochet.sources

  3. Installer l'agent sur chaque machine, ou le relais sur le serveur :

    sudo apt update && sudo apt install ricochet-agent
    sudo apt update && sudo apt install ricochet-serveur

  4. Relais : mettre nginx devant (modèle dans /usr/share/doc/ricochet-serveur/nginx-ricochet.conf), puis créer votre compte :

    sudo -u ricochet ricochet-serveur compte ajouter moi

  5. Agent : « Ajouter une machine » dans l'interface donne une commande à coller sur la machine, qui fait tout. À la main : écrire la configuration dans /etc/ricochet/agent.toml (droits 600), puis :

    sudo systemctl start ricochet-agent

Sans le dépôt : téléchargez les paquets .deb et leurs sommes de contrôle sur la page de la dernière version, puis sudo apt install ./ricochet-depot_*_all.deb ./ricochet-agent_*_amd64.deb. Le paquet ricochet-depot ajoute le dépôt : les mises à jour suivantes passent ensuite par sudo apt upgrade.
